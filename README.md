# Doce & Sabor 🍰

Protótipo de um cardápio digital responsivo para confeitaria e café.

## Tecnologias

- React
- Vite
- Tailwind CSS
- Lucide React

## Funcionalidades

- Home responsiva
- Cardápio por categorias
- Busca de produtos
- Modal de detalhes
- Carrinho com quantidade
- Checkout visual
- Acompanhamento de pedido
- Montador de bolo personalizado
- Dark mode / light mode
- Layout mobile-first

## Como executar

```bash
npm install
npm run dev
```

Depois abra a URL exibida pelo Vite.
